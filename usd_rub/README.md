# USD/RUB — моушн-вставка 1.2 с (Remotion)

1920×1080, 60 fps, 72 кадра. Делается кодом: React-сцена в Remotion, motion blur через `@remotion/motion-blur`, звук собирается Python-скриптом.

```
src/config.ts     ← все параметры: текст, цвета, кегль, тайминги, кол-во долларов/частиц
src/Scene.tsx     сцена: фон, блоб, доллары/купюры (3 слоя), боке, линия-график, текст, блик, зерно
src/Root.tsx      композиции UsdRub (MP4), UsdRubAlpha (прозрачная), UsdRubPreview
render.mjs        node render.mjs stills 6,18,30,42,66  |  node render.mjs final
audio/hpss.py     делит референс на музыку и перкуссию (HPSS на numpy)
audio/sfx.py      собирает public/sfx.wav: клики из референса + синтез whoosh/pop/shimmer
build.sh          полная пересборка с проверкой ffprobe
out/              usd_rub.mp4, usd_rub_alpha.mov
```

## Другой тикер
В `src/config.ts` меняется одна строка:

```ts
parts: ['EUR', '/', 'USD'],   // или ['BTC'], ['GOLD'], ['XAU', '/', 'USD']
```

Одиночный знак (`/`, `·`, `—`) автоматически рисуется тонким полупрозрачным разделителем с поворотом. Акцент по умолчанию у последней части (`accentIndex`). Для длинных слов уменьшите `fontSize`. Затем запустите `./build.sh`.

## Что взято из референса
Референс разобран по кадрам (ffmpeg, 10–30 fps, крупные планы).
- Слова выходят по очереди, примерно через 2 кадра при 30 fps (~70 мс), из сильного гауссова блюра, снизу вверх, с fade-in. Мягкий ease-out без перелёта.
- Входящее слово сначала окрашено акцентным цветом и за время проявления «остывает» к своему цвету. Эта деталь повторена: «USD» входит с зелёным оттенком и становится белым.
- Шрифт: гротеск в духе SF Pro / Inter Display, Bold, плотный трекинг. Здесь Inter Display Bold, −0.03em, «/» набран Light.
- Звук: музыкальная подложка (тональная, на всём протяжении), поверх неё короткие широкополосные клики на каждое появление и whoosh на смене сцены.

## Звук
Музыка в референсе звучит непрерывно, поэтому звуки нельзя вырезать «как есть». `hpss.py` отделяет перкуссионную часть медианной фильтрацией спектрограммы. Самый чистый транзиент (0.21 с) используется как клик, для «USD», «/» и «RUB» — в трёх вариантах высоты, с подложенным мягким синус-pop. Чистого whoosh под музыкой нет, поэтому он и shimmer синтезированы: шум с плавающим фильтром и стек высоких частиалей с тремоло. Пик −6 dBFS, fade-out 50 мс.

## Технические решения
- Фон, блоб и ореол текста рендерятся вне motion blur. Усреднение 6 сэмплов в 8 бит давало заметные ступеньки на тёмных градиентах.
- Блик — это слой с текстом, где `background-clip: text` и диагональный градиент (110°, то есть полоса под 20° от вертикали). Смещение фона считается от позиции каждой части, поэтому полоса проходит по всей строке непрерывно.
- Кончик линии-графика нарисован коротким светлым штрихом, а не точкой: точка распадалась на отдельные сэмплы motion blur.
- В альфа-версии нет подложки, виньетки и зерна. Блоб оставлен на 60 %: это световая подсветка под текстом.
