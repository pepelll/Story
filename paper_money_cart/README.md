# Paper money cart — анимированный фон 6 с (Python)

1080×1920, 30 fps, 180 кадров, без текста и звука. Всё рисуется кодом: pycairo для спрайтов, numpy/scipy для бумаги и света, кадры передаются в ffmpeg через pipe.

```
make_video.py   вся сцена: бумага, тени жалюзи, пачка $100, тележка, тонкий декор, наезд камеры
build.sh        превью-кадры → финальный MP4 → проверка ffprobe
out/            paper_money_cart.mp4
preview/        python3 make_video.py --preview (не коммитится)
```

Зависимости: `pip install numpy pillow scipy pycairo` и ffmpeg. Запуск: `./build.sh`.

## Что в кадре
- Серая бумага: зерно, перфорация точками, волокна, виньетка. Поверх неё медленно дрейфуют мягкие диагональные тени жалюзи (32°) и одна широкая тёмная полоса.
- Пачка из четырёх стилизованных купюр «100» въезжает из правого верхнего угла (0.15–1.6 с). Пустая тележка въезжает из левого нижнего (0.55–2.05 с). Обе с ease-out cubic, тень «садится» на бумагу по мере приземления, дальше лёгкое покачивание.
- Тонкий декор (1.1–2.5 с): горизонтальные линии с засечками и ромбом сверху и снизу, уголки по краям кадра.
- Камера делает медленный наезд на 4.5 % за весь ролик.

## Что крутить
Стартовые и конечные позиции объектов (`BILL_*`, `CART_*`) задаются в `main()`, длительность и fps в начале файла (`DURATION`, `FPS`), угол и скорость теней в `ANG` и `shadow_mask()`.
