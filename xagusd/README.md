# XAG/USD — моушн 3.5 с (canvas + Playwright)

1440×1080 (4:3), 60 fps, 210 кадров, только SFX, без музыки. Сцена рисуется кодом на canvas: `scene.html` отдаёт `window.renderFrame(t)`, `render.cjs` снимает кадры через Playwright и передаёт их в ffmpeg. Motion blur собирается из 4 подкадров на кадр (затвор 180°). Звук синтезирует `audio/sfx.py` (numpy).

```
scene.html     сцена и все параметры (CFG): цена, три большие свечи, тайминги. Открытая в браузере, проигрывается в цикле
render.cjs     node render.cjs stills 0.5,1.3,2.9  |  node render.cjs final
audio/sfx.py   UI-тики, поп-звуки, металлический клинк слитков, райзеры, импакты, чаймы, ревер
build.sh       полная пересборка с проверкой ffprobe
out/           xagusd.mp4 (финал), sfx.wav
```

## Таймлайн
- 0.00–0.6: фон из чёрного, сетка прорисовывается слева направо, шапка (Ag, XAG/USD, цена $57.20, +0.34 %)
- 0.24–0.9: 24 исторические свечи появляются по очереди, каждая со своим тихим тиком
- 0.50–1.3: три слитка падают с размытием и пружинят, звучит металлический клинк, по ним проходит блик
- 1.10 / 1.66 / 2.20: три большие свечи: $57 → $168 → $342 → $527. Шкала «выдыхает», камера трясётся, вспышка, искры, счётчик цены
- 2.80–3.5: финал: кольца, искры, блик по слиткам, пульс плашки +825 %, чайм

Текущая цена $57.20 взята по данным FXStreet на 19.10.2026. Чтобы поменять цену или цели, правьте `CFG` в `scene.html`, а тайминги дублируйте в начале `audio/sfx.py`.

Зависимости: playwright (Chromium), numpy, ffmpeg. Запуск: `./build.sh`.
